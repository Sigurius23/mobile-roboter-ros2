Here’s the whole node in one picture. Everything starts with a lidar scan: a ring of distance measurements, twenty times a second. For every scan, the node runs a function called scanCallback. TASK 1 converts the scan from the sensor’s frame into the robot’s frame. TASK 2 guesses how far the robot moved since the last scan. TASK 3, the ICP loop, shifts the old scan onto the new one and measures the real motion. That motion goes into a Kalman filter, which combines it with the other sensors. The filter’s result is the robot’s pose, which the node publishes on TF as odom to base_footprint. The wheels and the gyroscope feed the same filter through their own callbacks. That’s where Part 1 starts.
