WHY ALWAYS THE LATEST SCAN

Even if ICP failed: an ever older scan would make the gap, and the error, grow.

In pure-ICP mode the filter doesn’t run. ICP’s motion is added straight to the pose, and the node publishes it. Here ICP starts at zero, because the filter doesn’t run in this mode, so there’s no speed to guess from. The motion is in the robot’s frame: it’s rotated by the heading into the odom frame and added to the pose, like the odometry in Exercise 2. This branch publishes the transform itself. In every mode, at the end, the new scan becomes the old one, even if ICP failed. Comparing against an ever older scan would make the gap, and the error, grow.
