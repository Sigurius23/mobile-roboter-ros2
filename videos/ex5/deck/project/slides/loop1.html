std::vector: a list that can grow. for (const auto &p : list) gives each element in turn, without copying it.

WHY d² < 1.0

The tree already returns squared distances: d² < 1 means d < 1 m, no square root needed.

TRAP

A pair exactly 1 m apart is rejected: 1.0 < 1.0 is false.

Each round starts with two empty lists: the old points that found a partner, and their partners. In C++, a vector is a list that can grow. Step one: pairs. The loop goes over every old point; this kind of for loop gives each element in turn, by reference, without copying it. The kd-tree finds the one nearest new point. The pair is kept only if the squared distance is below one, so closer than one metre. The tree already returns squared distances, so comparing with one needs no square root. One trap in worked examples: a pair exactly one metre apart is rejected, because one is not smaller than one. If it’s close enough, the partner is looked up by its index and both points are added to the lists. With fewer than three pairs, the loop stops. Testat question: why one metre, not more or less? Too big, and points pair up with different objects. Too small, and there are no pairs when the guess is a bit off. Between two scans fifty milliseconds apart the robot moves about five centimetres, so one metre leaves a large margin.
