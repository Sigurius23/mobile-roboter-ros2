WHY PARAMETERS

The launch file sets them, so you switch modes without recompiling. icp_gain sets how much the filter trusts ICP (Part 4).

The constructor runs once, when the node starts. First it declares a parameter called icp_only with the default false, then reads its value into a member variable. In C++, the arrow on this means: call a function of this node object. Why parameters at all? The launch file can set them, so you switch modes without recompiling. Two switches give three modes. icp_only means ICP alone, without the filter. use_icp means the filter with ICP added. With both off, the filter runs on wheels and gyroscope only, like in Exercise 4, which is useful to compare against. The third parameter, icp_gain, sets how much the filter trusts ICP. Part 4 shows what it does and which value to choose.
